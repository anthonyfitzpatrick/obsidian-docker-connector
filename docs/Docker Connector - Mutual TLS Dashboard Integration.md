# Mutual TLS Dashboard Integration

Saved Docker API with TLS profiles participate in startup, manual, and automatic refresh through the shared Docker snapshot services. Containers, images, volumes, networks, and lazy details are mapped exactly as for Local Docker, SSH, and Docker Context profiles. Failed refreshes retain a previous successful snapshot as stale data; client-key passphrases remain runtime-only.
