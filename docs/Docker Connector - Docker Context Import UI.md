# Docker Context Import UI

The host dialog can discover and safely display Docker CLI Contexts. Discovery is read-only and never changes the active Context. New profiles can be saved from a supported discovery result; saved supported Contexts use the normal Test Connection and dashboard refresh pipeline after lifecycle preflight. See [[Docker Connector - Docker Context Editing]] and [[Docker Connector - Docker Context Execution]].
