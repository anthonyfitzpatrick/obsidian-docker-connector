# Reports

The current project does not generate reports, so Applications are not exported in this release. If host reports are introduced later, they should include only project, service, container, running, health, and update counts from [[Docker Connector - Applications View]], never raw Compose configuration or environment values.

Docker Connector does not currently generate portfolio reports. The Connections view safely presents Docker Context name, endpoint type, lifecycle status, import time, and last metadata check without resource counts, raw endpoint URLs, or secrets.
