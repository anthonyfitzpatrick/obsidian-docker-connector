# Connections View

The Connections view presents Local Docker, SSH, Docker API mutual-TLS, and saved Docker Context profiles. Context cards show safe saved metadata and read-only lifecycle status, with Edit, View Context Details, and Refresh Context Metadata actions. Context profiles use the normal read-only refresh after lifecycle preflight. See [[Docker Connector - Docker Context Execution]], [[Docker Connector - Docker Context Editing]], and [[Docker Connector - Docker API TLS Connections]].
